MDRRMO VERCEL + SUPABASE DEPLOYMENT
1. Create a Supabase project. Open SQL Editor and run SUPABASE_SETUP.sql.
2. In Supabase Project Settings > API copy Project URL and service_role key (secret).
3. Create a GitHub repository and upload this project folder (do NOT upload .env files with secrets).
4. Import the repository into Vercel.
5. Add Vercel Environment Variables:
   SUPABASE_URL = your Supabase Project URL
   SUPABASE_SERVICE_ROLE_KEY = your Supabase service_role key
   ADMIN_PASSWORD = choose the admin password
   VIEWER_PASSWORD = choose the viewer password
   SESSION_SECRET = a long random secret (32+ characters)
6. Redeploy. Open the Vercel URL.
7. Log in as MDRRMO. The admin password gives full access; the viewer password gives view/filter/export access only.
8. As admin, import your existing JSON backup to move current records into the shared database.
IMPORTANT: start.bat/.exe are for the old local system. Vercel uses the api folder and Supabase.
